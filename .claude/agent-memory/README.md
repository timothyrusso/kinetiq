# Agent memory

One file per agent that learns on the job (`qa-engineer.md`, `qa-web-engineer.md`), created by the
agent on its first lesson. The convention is the plugin's `agent-memory/README.md` in
agentic-kit: only reusable operational knowledge, one dated line per lesson
(`- [YYYY-MM-DD] <lesson>`), update or delete before adding, about 40 lines per file, and each
change committed on its own as `chore(<issue>): qa lesson, <short slug>`. Humans curate at PR
review.
