# Testbook

Release QA test cases, run by an agent with agent-device before every release.

- One section per flow, one bullet per test case.
- Each bullet is one short sentence: an action and what must be true after it.
- Run the bullets of a section top to bottom; each section starts on the Home tab unless it says otherwise.
- Report PASS or FAIL for every bullet, with a screenshot for every FAIL.
- A new feature or flow adds its section or bullets in the same PR.

## New routine from empty

- Open the Workout tab and tap New routine: the empty routine editor opens.
- Give the routine a name: the name shows in the editor.
- Tap Add exercise: the Add exercise sheet opens over the editor.
- Check the sheet: its top edge stands out from the dimmed page behind it.
- Check the list: every row shows a photo or initials, a name and tags.
- Search "bench": bench press exercises are at the top.
- Clear the search: the full list shows from the top.
- Select a muscle filter chip: only exercises for that muscle show.
- Remove the filter: the full list shows from the top, with no jump.
- Tap an exercise row: it is added and the row shows a filled check.
- Tap the same row again: it is removed and the row shows a plus.
- Add three different exercises: each row shows a filled check.
- Tap the info button on a row: the exercise page opens and its photo moves.
- Go back from the exercise page: the sheet keeps its search, filter and checks.
- Close the sheet: the editor lists the three exercises in the order they were added.
- Tap an exercise in the editor: its sheet shows every set, rest, note and a moving photo.
- Tap the photo: the exercise page opens, and back returns to the sheet.
- Close the exercise sheet and save the routine: it appears in the Workout tab with three exercises.
- Open the routine again: the three exercises and their sets are still there.
